# Assignment 2: Student Information Management

This is a React-based web application that displays and manages student information using Props. 

## Features
- **Student Cards**: Displays Name, Roll Number, Department, Semester, CGPA, and a Profile Photo for each student.
- **Component-Based Architecture**: Includes `App`, `Header`, `Footer`, `StudentList`, and `StudentCard` components.
- **Data Flow**: All student data is passed down through React Props.
- **Sorting Mechanism**: Allows sorting students by their CGPA (Highest to Lowest and vice versa).
- **Modern UI**: Clean and intuitive interface with a premium dark mode design.

## Technologies Used
- React
- Vite
- HTML5 / CSS3 / JavaScript

## Setup Instructions

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/assignment-2-student-management.git
   ```

2. Navigate into the project directory:
   ```bash
   cd assignment-2-student-management
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173` to view the site.
